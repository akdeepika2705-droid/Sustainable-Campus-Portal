# EcoCampus Hub 🌿

A comprehensive, responsive Single-Page Application (SPA) designed to drive practical, sustainable development across university and college campuses.

## ✨ Core Features
* **Role-Based Authentication:** Login portal for Students, Faculty, and Event Organizers.
* **Report a Problem:** Log water leaks, electricity waste, and plastic accumulation with automatic history persistence.
* **Waste Disposal Guide:** Interactive cards detailing disposal protocols for Dry, Organic, E-Waste, and Hazardous materials.
* **Save Resources:** Daily action checklists providing practical tips to conserve energy, paper, and water.
* **Green Challenges & Leaderboard:** Gamified environmental actions with photographic proof uploads, tier-based points, and separate Student/Faculty rankings celebrated with dynamic confetti.
* **Green Event Planner:** Interactive calendar for browsing eco-friendly events and scheduling zero-waste gatherings.
* **Sustainability Dashboard:** Interactive analytics powered by Chart.js tracking waste segregation and weekly resource trends.
* **Idea Hub & Shared Ideas:** Submit, filter, and upvote innovative campus green initiatives.

## 🛠️ Tech Stack
* **Frontend Framework:** HTML5, CSS3, JavaScript (ES6+)
* **UI Library:** Bootstrap 5 & FontAwesome Icons
* **Data Visualization:** Chart.js
* **Effects:** Canvas-Confetti
* **Storage:** Browser LocalStorage / Memory State
